php embeded youtube url

如果你的 DB 里面存的是普通 YouTube URL，例如：

https://www.youtube.com/watch?v=dQw4w9WgXcQ

PHP 页面可以转换成 embed：

<?php
$url = $p->video_url;

parse_str(parse_url($url, PHP_URL_QUERY), $query);

$videoId = $query['v'] ?? '';

if ($videoId):
?>
    <iframe
        width="560"
        height="315"
        src="https://www.youtube.com/embed/<?= htmlspecialchars($videoId) ?>"
        frameborder="0"
        allowfullscreen>
    </iframe>
<?php endif; ?>
如果你的 URL 是
https://www.youtube.com/watch?v=abc123

就会变成：

https://www.youtube.com/embed/abc123

然后显示：

<iframe src="https://www.youtube.com/embed/abc123"></iframe>
更简单的写法

如果你确定 DB 一定是：

https://www.youtube.com/watch?v=VIDEO_ID

可以：

<?php
$videoId = explode('v=', $p->video_url)[1] ?? '';
?>

<?php if ($videoId): ?>
    <iframe
        width="560"
        height="315"
        src="https://www.youtube.com/embed/<?= htmlspecialchars($videoId) ?>"
        allowfullscreen>
    </iframe>
<?php endif; ?>

我比较推荐第一种，因为比较安全，也比较不容易因为 URL 后面有其他参数而出错。
