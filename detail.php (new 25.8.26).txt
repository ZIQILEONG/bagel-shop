<?php
include __DIR__ . '/../_base.php';

$id = get('id');
if (!$id) {
    redirect('/product/list.php');
}

// Handle Add to Cart (POST)
if (is_post()) {
    $unit = req('unit');
    if ($unit > 0) {
        update_cart($id, $unit);
        set_flash('Added to cart successfully!', 'success');
    } else {
        set_flash('Please select a quantity.', 'error');
    }
    redirect(); // Redirect to same page to clear POST data
}

// Fetch Product Details
$sql = "SELECT p.*, c.name as category_name 
        FROM product p 
        LEFT JOIN category c ON p.category_id = c.id 
        WHERE p.id = ?";
$product = db_query($sql, [$id])->fetch();

if (!$product) {
    die("Product not found.");
}

// Fetch Multiple Photos
$photos_sql = "SELECT * FROM product_photo WHERE product_id = ? ORDER BY sort_order ASC, id ASC";
$photos = db_query($photos_sql, [$id])->result();

// Fallback: If no extra photos, use the main product photo
if (empty($photos)) {
    $photos = [(object)['filename' => $product->photo, 'is_main' => true]];
}

// Fetch Reviews
$reviews_sql = "SELECT r.*, u.username FROM product_review r 
                JOIN user u ON r.user_id = u.id 
                WHERE r.product_id = ? 
                ORDER BY r.created_at DESC";
$reviews = db_query($reviews_sql, [$id])->result();

// Get current cart quantity
$cart = get_cart();
$current_qty = $cart[$id] ?? 0;

$_title = $product->name . ' | Pululu Bagel';
include __DIR__ . '/../_head.php';

<script>
$(document).ready(function() {
    // Image Slider Logic
    window.changeImage = function(img) {
        $('#mainImage').attr('src', $(img).attr('src'));
        $('.thumb-item').removeClass('active');
        $(img).addClass('active');
    };

    // Quantity Logic
    const maxStock = <?= $product->stock ?>;
    
    $('#btnPlus').click(function() {
        let val = parseInt($('#qtyInput').val());
        if (val < maxStock) {
            $('#qtyInput').val(val + 1);
        }
    });

    $('#btnMinus').click(function() {
        let val = parseInt($('#qtyInput').val());
        if (val > 1) {
            $('#qtyInput').val(val - 1);
        }
    });

    // Prevent manual input exceeding stock
    $('#qtyInput').on('change', function() {
        let val = parseInt($(this).val());
        if (val > maxStock) $(this).val(maxStock);
        if (val < 1) $(this).val(1);
    });
});
</script>

Multiple Photo Slider:
Fetches all images from product_photo table.
Displays a large main image.
Shows thumbnails below; clicking a thumbnail updates the main image instantly using jQuery.
Falls back to the single product.photo if no extra photos exist.
Quantity Controls (+/-):
Custom buttons to increment/decrement quantity.
Logic Check: Prevents adding more than the available stock.
If the item is already in the cart, it pre-fills the quantity and changes the button text to "Update Cart".
Video Integration:
Checks if video_url exists in the database.
Automatically converts standard YouTube links to Embed links for display.
Reviews:
Lists existing reviews with star ratings.
Provides a link for logged-in users to write a review.
Stock Management:
Shows "In Stock" or "Out of Stock" badges.
Disables the "Add to Cart" button if stock is 0.
How to Test:
Ensure you have inserted rows into product_photo via phpMyAdmin for a specific product ID.
Navigate to that product's detail page (e.g., http://localhost/bagel-shop/product/detail.php?id=1).
You should see the gallery slider, the video (if added), and the working +/- buttons.
